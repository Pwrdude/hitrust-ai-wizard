# SC: AI supply chain

## SC-01 Due diligence review of AI providers

HITRUST ID `14.09fAISecSystem.1` · Domain 14 Third Party Assurance · Control 09.f Monitoring and Review of Third Party Services  
Inheritable: No · Applies: all model types

> The security posture of external commercial providers of AI models, datasets, software packages, platforms and infrastructure, and language model tools is evaluated at onboarding and routinely afterward.

Evaluative elements:
- `SC-01[1]` Model providers evaluated
- `SC-01[2]` Dataset providers evaluated
- `SC-01[3]` Software package providers evaluated
- `SC-01[4]` Platform and infrastructure providers evaluated
- `SC-01[5]` Language model tool providers evaluated _(if agents/plugins)_
- `SC-01[6]` Evaluated at onboarding
- `SC-01[7]` Evaluated routinely under supplier oversight

Note: Dual responsibility.

## SC-02 Review the model card of models used by the AI system

HITRUST ID `14.05iAISecOrganizational.1` · Domain 14 Third Party Assurance · Control 05.i Identification of Risks Related to External Parties  
Inheritable: No · Applies: all model types, only when externally sourced models used

> For externally sourced models deployed in production applications, the model card is reviewed before deployment.

Evaluative elements:
- `SC-02[1]` Model card reviewed before deployment

Note: Applies to externally sourced models in production. AI application provider's sole responsibility.

## SC-03 AI security requirements communicated to AI providers

HITRUST ID `14.05kAISecOrganizational.1` · Domain 14 Third Party Assurance · Control 05.k Addressing Security in Third Party Agreements  
Inheritable: No · Applies: all model types

> Agreements with external providers of AI system components and services clearly communicate the organization's AI security requirements.

Evaluative elements:
- `SC-03[1]` Agreements with model providers
- `SC-03[2]` Agreements with dataset providers
- `SC-03[3]` Agreements with software package providers
- `SC-03[4]` Agreements with platform and infrastructure providers
- `SC-03[5]` Agreements with language model tool providers _(if agents/plugins)_
- `SC-03[6]` Agreements for contracted AI system services

Note: Joint responsibility, normally through a jointly executed agreement.
